# Terminal.Gui XAML Framework

[![Build Status](https://github.com/terminal-gui-xaml/Terminal.Gui.Xaml/workflows/PR%20Validation/badge.svg)](https://github.com/terminal-gui-xaml/Terminal.Gui.Xaml/actions)

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A comprehensive XAML framework for [Terminal.Gui v2+](https://github.com/gui-cs/Terminal.Gui) that enables declarative UI development with Microsoft XAML standards compatibility. Build rich terminal user interfaces using familiar XAML markup with full cross-platform support.

## 🚀 Features

- **Microsoft XAML Compatibility**: Uses standard XAML syntax and conventions
- **Roslyn Code Generation**: Build-time code generation for optimal performance  
- **Cross-Platform**: Works on Windows, Linux, and macOS via .NET 8+
- **MVVM Support**: Full data binding and property change notification
- **Performance Optimized**: Constitutional performance guarantees:
  - XAML parsing <100ms
  - UI rendering >30 FPS
  - Memory usage <50MB
  - Initialization <50ms
- **Design-Time Support**: IntelliSense and tooling integration
- **Minimal Dependencies**: Uses only .NET 8+ and Terminal.Gui v2+

## 🏁 Quick Start

### Installation

```bash
dotnet add package Terminal.Gui.Xaml
```

### Create Your First XAML Application

**1. Create XAML file** (`MainWindow.xaml`):
```xml
<Window xmlns="http://schemas.terminal-gui.org/xaml"
        Title="Hello XAML" Width="80" Height="25">
    <StackView Orientation="Vertical">
        <Label Text="Welcome to Terminal.Gui XAML!" />
        <Button x:Name="ClickMe" Text="Click Me" Clicked="OnClickMeClicked" />
        <TextField x:Name="UserInput" Text="{Binding UserText}" />
        <Label Text="{Binding DisplayText}" />
    </StackView>
</Window>
```

**2. Create code-behind** (`MainWindow.xaml.cs`):
```csharp
using Terminal.Gui;
using Terminal.Gui.Xaml;

namespace HelloXaml;

public partial class MainWindow : Window
{
    public string UserText { get; set; } = "";
    public string DisplayText { get; set; } = "Enter text above";
    
    public MainWindow()
    {
        InitializeComponent(); // Generated by XAML framework
        DataContext = this;
    }
    
    private void OnClickMeClicked(object? sender, EventArgs e)
    {
        DisplayText = $"You entered: {UserText}";
    }
}
```

**3. Run your application** (`Program.cs`):
```csharp
using Terminal.Gui;
using HelloXaml;

Application.Init();
Application.Run(new MainWindow());
Application.Shutdown();
```

**4. Build and run**:
```bash
dotnet build
dotnet run
```
