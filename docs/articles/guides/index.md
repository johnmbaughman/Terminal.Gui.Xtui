# Guides

Step-by-step instructions for common Terminal.Gui.Xaml development tasks.

These guides provide practical, actionable instructions for implementing specific features and scenarios in your Terminal.Gui.Xaml applications.

## Getting Things Done

- **[Create a Window](create-window.md)** - Set up your first Terminal.Gui.Xaml window with proper structure
- **[Bind Data](bind-data.md)** - Implement data binding with view models and INotifyPropertyChanged
- **[Handle Input](handle-input.md)** - Process user input, validation, and keyboard shortcuts
- **[Navigation](navigation.md)** - Manage multiple windows and application flow
- **[Accessibility](../accessibility.md)** - Make your applications accessible to all users

## Guide Structure

Each guide follows a consistent pattern:

1. **What You'll Learn** - Clear learning objectives
2. **Prerequisites** - What you need before starting
3. **Step-by-Step Instructions** - Detailed implementation steps
4. **Complete Example** - Working code you can copy and run
5. **Troubleshooting** - Common issues and solutions
6. **Next Steps** - Related guides and advanced topics
